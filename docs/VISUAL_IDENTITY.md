# Identidad visual — La Piedad Operaciones

## Marca

- Nombre institucional: **La Piedad**.
- Nombre del producto: **La Piedad Operaciones**.
- El símbolo se usa sin deformar, recolorear ni separar sus elementos.
- En interfaz, el símbolo aparece junto al nombre `La Piedad` y al descriptor `Operaciones`.

## Paleta

| Uso | Color |
| --- | --- |
| Acción principal | `#8B1E3F` |
| Vino oscuro | `#64152D` |
| Acento dorado | `#D4AF5A` |
| Fondo marfil | `#F6F1E8` |
| Superficie cálida | `#FBF8F2` |
| Borde | `#E7DED2` |
| Texto principal | `#2E221F` |
| Texto secundario | `#8A8178` |

Los estados funcionales mantienen colores propios: éxito `#2E7D4F`, advertencia `#C28A22`, error `#B23A3A` e información `#3A6EA5`.

## Tipografía

- El nombre institucional y los titulares de marca usan la pila local `Georgia, Times New Roman, serif`.
- Formularios, navegación y datos operativos usan `Inter` con alternativas del sistema.
- No se cargan fuentes remotas para conservar el funcionamiento sin conexión.
